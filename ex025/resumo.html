Resumo de formulários

O que é um formulário?

Um formulário HTML coleta dados do usuário e envia essas informações para um servidor. Ele pode ser usado para cadastro, login, contato, pesquisa e envio de documentos.

Estrutura básica

A tag form envolve os campos. O atributo action indica para onde os dados serão enviados, e method="post" envia os dados no corpo da requisição, sendo mais apropriado para senhas e cadastros do que o método get. O atributo autocomplete="on" permite que o navegador ajude a preencher os campos.

Rótulos e campos

Cada campo deve ter um label. O valor de for deve ser igual ao id do campo. Isso melhora a acessibilidade e permite clicar no texto para selecionar o campo. O atributo name é o nome usado pelo servidor para receber o valor enviado.

Exemplo revisado

<form action="cadastro.php" method="post" autocomplete="on">
    <p>
        <label for="iusu">Usuário:</label>
        <input type="text" name="usu" id="iusu"
            required minlength="10" maxlength="15"
            placeholder="Digite seu usuário"
            autocomplete="username">
    </p>

    <p>
        <label for="isen">Senha:</label>
        <input type="password" name="sen" id="isen"
            required minlength="8" maxlength="20"
            placeholder="Digite sua senha"
            autocomplete="current-password">
    </p>

    <p>
        <input type="submit" value="Enviar">
        <input type="reset" value="Limpar">
    </p>
</form>

O que os atributos fazem?

  • type="text": campo para texto comum.
  • type="password": esconde os caracteres digitados.
  • required: torna o preenchimento obrigatório.
  • minlength e maxlength: definem limites de caracteres.
  • placeholder: mostra uma dica dentro do campo; não substitui o label.
  • size: altera apenas a largura visual aproximada do campo.
  • submit: envia o formulário.
  • reset: limpa os valores preenchidos.

Como fazer um formulário profissional

Use labels claros, campos com o tipo correto, mensagens de erro compreensíveis e validação no navegador e no servidor. Nunca confie somente no HTML: o PHP precisa validar os dados novamente, proteger contra ataques e armazenar senhas usando hash, nunca em texto puro. Em produção, use HTTPS, proteção contra CSRF, controle de sessão e limite de tentativas de login.

Para trabalhar futuramente na Suíça, prepare formulários acessíveis, responsivos e prontos para internacionalização. Considere alemão, francês, italiano e inglês; não fixe textos, formatos de data ou moeda em um único idioma. Informe claramente os campos obrigatórios, peça apenas os dados necessários e trate dados pessoais conforme a proteção de dados aplicável, especialmente a FADP/LPD suíça e, quando houver usuários da União Europeia, o GDPR.

Melhorias para estudar depois

  • Adicionar fieldset e legend para agrupar campos relacionados.
  • Aprender campos como email, tel, date e select.
  • Usar autocomplete adequado, como email, tel e postal-code.
  • Testar teclado, celular, leitores de tela e mensagens de erro.
  • Aprender PHP para validar, higienizar e processar os dados com segurança.
